# Интернет-магазин

Интернет-магазин на React.

Демо: https://dimiatr.github.io/smallShop/

## Возможности

- Главная страница с категориями товаров
- Каталог товаров по категориям с фильтром по цене
- Страница товара
- Корзина: добавление, изменение количества, удаление товаров, подсчёт суммы
- Избранное
- Форма оформления заказа

## Технологии

- React
- Vite
- React Router DOM
- Tailwind CSS
- Context API
- localStorage
- ESLint

## Запуск локально

```bash
npm install
npm run dev
```

Сборка для продакшена:

```bash
npm run build
```
