# Интернет-магазин

Проект интернет-магазина на React.

В проекте реализованы:

- главная страница с категориями
- страницы товаров
- избранное
- корзина
- роутинг между страницами

Использованные технологии:

- React
- Vite
- React Router DOM
- Tailwind CSS
- Context API
- localStorage
- ESLint


ps разработка велась локально, поэтому всё одним коммитом.
